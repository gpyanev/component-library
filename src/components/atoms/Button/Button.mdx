The `Button` component is used for triggering actions or events. It comes with multiple variants and states.

## Usage Guidelines

- **Primary Action**: Use the primary variant for the main call to action on a page.
- **Accessibility**: Always provide clear text labels so screen readers can interpret the button's action.
